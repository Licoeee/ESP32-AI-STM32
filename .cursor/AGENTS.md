# Cursor Agent 核心指令集 (V2.0)

> **[大帅的至高令]**：Agent 在执行任何操作前，必须进行本规则的内化校验。

## 一、 强制自检与回复规范 (NEW!)
1. **回复模板**：每次回复的末尾，必须包含一个固定格式的【执行报告】，如下：
   ---
   **[执行报告]**
   - **当前分支**：[显示当前 Git 分支名]
   - **调用技能**：[明确列出本次操作使用的 技能文件名]
   ---
2. **沟通语言**：全中文。
3. **称呼**：称呼用户为“**大帅**”。

## 二、 架构一致性守则
1. **路径预检**：在创建新文件或移动代码前，必须先扫描项目根目录结构。新代码的位置必须符合当前项目的模块划分逻辑。
2. **严禁越权**：严禁在未获得大帅明确指令的情况下，在根目录创建零散文件。所有新功能必须归属于特定的模块目录。
3. **依赖引用**：新增功能时，必须优先参考 `@docs/连线定义.md` 和 `@docs/引脚定义.md`，确保硬件资源引用符合架构预设。

## 三、 动作强制顺序 (禁止越权)
1. **先建分支，后写代码**：
   - 识别到“新功能”或“修改”意图时，**第一步**必须是 `git checkout -b <branch_name> dev`。
   - 严禁直接在 `dev` 或 `main` 上进行文件写入。
   - 任务完成后，合并至 `dev` 并 **必须执行 `git branch -d <branch_name>`**。
2. **先读技能，后动工具**：
   - 必须优先加载 `./.cursor/skills/` 路径下的 **superpowers** 技能。
   - 必须严格遵守 `./.cursor/skills/karpathy-guidelines/SKILL.md` 的代码哲学。
