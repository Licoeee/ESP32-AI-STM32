# 连线定义

> 说明：以下表格统一采用 **左侧 = ESP32S3 开发板引脚**，**右侧 = 设备引脚/说明** 的排版。

## 1) 麦克风（INMP441 / ICS43434，I2S）

| ESP32S3开发板（左） | 设备引脚/说明（右） |
|---|---|
| GPIO4 | WS（数据选择） |
| GPIO5 | SCK（数据时钟） |
| GPIO6 | SD（数据输出） |
| 3V3 | VDD / 3.3V（电源正） |
| GND | GND（接地）与 L/R 短接选择左/右声道 |

---

## 2) 数字功放（MAX98357A）

| ESP32S3开发板（左） | 设备引脚/说明（右） |
|---|---|
| GPIO7 | DIN（数字音频输入） |
| GPIO15 | BCLK（位时钟） |
| GPIO16 | LRC（左右声道时钟） |
| 3V3 | VIN / VCC（3.3V 电源输入）与 SD 短接 |
| GND | GND（接地）与 GAIN 短接 |

---

## 3) 显示屏（IIC / I2C，可选）

| ESP32S3开发板（左） | 设备引脚/说明（右） |
|---|---|
| GPIO41 | SDA（数据线） |
| GPIO42 | SCL / SCK（时钟线） |
| 3V3 | VCC（电源正） |
| GND | GND（接地） |

---


## 4) 按钮

| ESP32S3开发板（左） | 设备引脚/说明（右） |
|---|---|
| GPIO39 | 音量减按钮（另一端接 GND）；短按减小音量，长按静音（音量 0） |
| GPIO40 | 音量加按钮（另一端接 GND）；短按增大音量 |
